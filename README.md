## 1. Giới thiệu
Portfolio giới thiệu thông tin cá nhân, quá trình học tập, kỹ năng và các sản phẩm học tập của sinh viên. Nội dung cụ thể cần được đối chiếu với mã nguồn thực tế trong repository.

## 2. Cấu trúc dự án
Cập nhật cây thư mục đúng với repository trước khi bàn giao. Ví dụ:

```text
K20_Portfolio_CNTT20_04/
├── index.html
├── css/
├── assets/
├── README.md
├── AI_LOG.md
└── RELEASE_NOTES.md
```

## 3. Chạy thử trên máy tính
1. Clone repository:
   ```bash
   git clone https://github.com/vanquocbao412-beep/K20_Portfolio_CNTT20_04.git
   ```
2. Mở thư mục dự án bằng VS Code.
3. Mở `index.html` trực tiếp trên trình duyệt hoặc dùng tiện ích Live Server.
4. Kiểm tra các liên kết, hình ảnh, CSS và các chức năng có trên trang.

## 4. Triển khai GitHub Pages
Trong GitHub, mở **Settings → Pages**, chọn đúng branch chứa mã nguồn và thư mục `/ (root)` hoặc `/docs` theo vị trí `index.html`. Lưu cấu hình, chờ workflow deploy hoàn tất rồi mở URL được GitHub cung cấp.
